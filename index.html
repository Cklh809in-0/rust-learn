Ownership & Borrowing (H–L)

Đây là tính năng độc đáo nhất của Rust — hiểu được Ownership là hiểu được Rust.

H Ownership

✓
Ba quy tắc:
  1. Mỗi giá trị có một owner
  2. Khi owner ra khỏi scope, giá trị bị drop
  3. Có thể borrow thay vì chuyển

Move vs Clone

let s1 = String::from("hello");
let s2 = s1;  // MOVE
let s3 = s2.clone(); // deep copy

I References & Borrowing

✓
🦀 Borrowing
fn calc_len(s: &String) -> usize { s.len() }
let s1 = String::from("hello");
let len = calc_len(&s1);
println!("{}: {}", s1, len);

// Mutable ref — chỉ 1 lần
let mut s = String::from("hi");
let r1 = &mut s;
// let r2 = &mut s; // LỖI!

J Slices

✓
🦀 Slices
fn first_word(s: &str) -> &str {
    for (i, &item) in s.as_bytes().iter().enumerate() {
        if item == b' ' { return &s[0..i]; }
    } &s[..]
}

K Lifetime

✓
🦀 Lifetime
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
struct Excerpt<'a> { part: &'a str }

L Error Handling

✓

Result<T, E>

fn read_file() -> Result<String, std::io::Error> {
    let mut f = File::open("hello.txt")?;
    let mut s = String::new();
    f.read_to_string(&mut s)?; Ok(s)
}

Option<T>

fn find(list: &[i32], t: i32) -> Option<usize> {
    for (i, &v) in list.iter().enumerate() {
        if v == t { return Some(i); }
    } None
}

Q Async/Await

✓
🦀 Async (tokio)
// tokio = { version = "1", features = ["full"] }
use tokio::time::{sleep, Duration};

async fn hello() -> &'static str {
    sleep(Duration::from_secs(1)).await;
    "Hello async!"
}

#[tokio::main]
async fn main() {
    println!("{}", hello().await);
}
